# Security Policy

## Supported versions

We investigate security reports affecting the latest version of CareMatch on the default branch. If you found an issue in an older version, please include the affected version or commit.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the repository’s **Security** tab using **Report a vulnerability**, if available. If private reporting is unavailable, contact the repository maintainer privately. Please keep vulnerability details out of public issues, pull requests, and discussions.

Include the affected app version or commit, a short description, steps to reproduce the issue using test data, and the potential impact. Redact patient information, credentials, tokens, and payment details from any screenshots or logs.

## Testing and disclosure

Use test accounts you control and synthetic data. Avoid accessing other users’ accounts or records, initiating real payments, or disrupting the service. If you encounter sensitive data, stop testing and report what happened without copying or sharing the data.

We’ll review credible reports and coordinate next steps with the reporter. Please give the maintainer a reasonable opportunity to investigate and address the issue before publishing details.
